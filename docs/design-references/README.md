# UI-Referenzen für Foliq

Vom Nutzer am 2026-11-10 bereitgestellte OneNote-Screenshots als visuelle Orientierung für Foliq.

- 2735.png: Normalansicht und Textwerkzeuge
- 2731.png: reduzierter Fokusmodus mit schwebender Zeichenleiste
- 2732.png: Zeichenwerkzeuge
- 2734.png: Einfügewerkzeuge
- 2733.png: Ansichtsoptionen

Gestaltungsrichtung: dunkle Werkzeugbereiche, farbige Abschnittsreiter, rechte Seitenliste und große Schreibfläche. Foliq erhält eigene Gestaltungselemente und bleibt beim gemeinsamen GTK/C++-Editor. Die Bilder zeigen OneNote, keine bereits implementierte Foliq-Oberfläche. Sie werden unverändert als Referenz aufbewahrt; die GPL-Lizenz des Foliq-Codes wird ihnen nicht zugeschrieben.
