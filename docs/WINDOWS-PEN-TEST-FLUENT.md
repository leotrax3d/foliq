# Manuelle Prüfung auf dem Windows-Stiftrechner (Fluent-UI)

Paket aus der Windows-CI (UCRT64) des Branches entpacken, Foliq starten.
Jede Zeile mit OK/Fehler + Screenshot notieren; Skalierung 100/150/200 % über
Windows-Einstellungen → Anzeige wiederholen.

1. Start: Befehlsleiste mit Registerkarten, Icons scharf, keine klassische
   Menüleiste; ⋯ (oder F10) zeigt alle bisherigen Menüs; Strg+S/Strg+Z wirken.
2. Stift: In „Zeichnen" Stift wählen, Druck variieren → Strichbreite ändert
   sich. Radierer-Ende des Stifts radiert. Hand auflegen beim Schreiben →
   keine Fremdstriche (Handballenfilter wie bisher).
3. Menüband einklappen (Pfeil rechts oben/Strg+F1). Registerkarte antippen:
   Menüband schwebt über der Seite. Mit dem Stift direkt auf die Seite
   schreiben: Menüband schließt, **der erste Strich ist vollständig**.
4. Während das Menüband/die Navigation auf- oder zuklappt, schreiben: kein
   abgebrochener oder versetzter Strich.
5. Textwerkzeug, Text tippen, dann Menüband-Befehl (z. B. Stift/Formatieren)
   antippen: kein unerwarteter Fokusverlust, deutsche Umlaute/AltGr gehen.
6. Ansicht → Berührung: größere Schaltflächen und Navigationszeilen; alle
   Befehle weiterhin vorhanden. Zurück auf Kompakt.
7. Ansicht → Hell/Dunkel/System, Akzentfarbe (z. B. Gelb-ähnlich „Orange"):
   Auswahl, Reiterlinie und Seitenkontur bleiben gut sichtbar.
8. Navigation: Pin lösen → Navigation schwebt; Seite öffnen → schließt.
   Fokusmodus (Strg+Umschalt+F). Neustart: Zustände bleiben erhalten.
9. Abschnitt → Aktionen → Farbe…: Punkt erscheint; Neustart: bleibt.
10. Speicherfehler provozieren (Notizbuchordner schreibschützen, schreiben,
    5 s warten): rote Statusmeldung; Schutz aufheben → „Gespeichert".
11. PDF annotieren, exportieren (⋯ → File → Export as PDF), Datei öffnen.
12. Narrator (Strg+Win+Enter): Icon-Buttons werden mit Namen angesagt;
    F6 wechselt Navigation → Seiten → Registerkarten → Editor.
